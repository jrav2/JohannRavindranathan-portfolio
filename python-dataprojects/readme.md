# About this page

This folder contains four of the projects I completed for Geography 450: Visualizing Seattle. These were bi-weekly assignments that practiced our data collection and data processing skills. The subject material for these projects focused on Seattle and its immediate surroundings.<br>

Data for these projects came from online resources, and by field observations made by myself and / or classmates. Much of the technical work was completed in Jupyter notebooks using Python and a variety of data wrangling packages, namely Pandas, as well as external applications when necessary.<br> 

Work files, reports, and additional information are provided in each project's folder. 

The first project covered movements through Seattle, which we turned into a Sankey diagram flowchart.<br>

The second project dealt with observational data from Ballard, and how this data described life in the neighborhood.<br>

The third project saw us turn visual data (pictures of the sky) into a description of Seattle.<br>

The fourth project covered places near UW that my classmates and I frequent, and turning individual posts into insights on the daily routine of college students.
