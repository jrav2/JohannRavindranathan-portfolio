# About this page

### SQL
I first interacted with SQL and querying in QGIS and ArcGIS Pro. In those applications, querying was a means to grab relevant data for the analysis I was conducting. Subsequently I spent time dedicated to PostgreSQL in pgAdmin. I learnt about the development of databases, how organizational scheme has changed over time, then practiced writing queries and moving geographic data into tables. 
<br>

I have included one practice item, which contains images of queries used to meet the instructions (not all code is shown, only those relevant to the assignment questions). It began by initializing a set of data tables with spatial information for fast food locations, and culminated in linking the tables to QGIS for visualization. 

### Movie Theater
A later project has been included, which pivoted towards creating webpages and integrating digital maps. We reviewed HTML/CSS/JS, which I worked with previously in the EV Charger map, and explored different options for stylizing and adding features to interactive maps. 
<br>

In this folder I have included the material I used to create a webpage that integrated a basemap from Thunderforest and scripting from Leaflet. The project required us to use specific objects in the map, as a demonstration of what we learned during the course. I met those requirements by highlighting some prominent features near Seattle WA.
