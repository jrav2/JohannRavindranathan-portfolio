# About this page

This folder contains some coursework that dealt with data science in R. This was an introduction to the R language and to RStudio as a development environment. Most work was done in Quarto documents and slideshows using Reveal.js inputs. I gained experience creating data visualizations using ggplot2 and data wrangling with packages like dplyr and tidyverse. This was also an introduction to thinking like a data scientist, and understanding the outcome to decisions made on missing data, unexpected outputs, and flawed data retrieval. <br>

Included here are two of the projects completed during this time. The first was the final project, which was a final demonstration of the skills we learned. This was a group project between myself and my teammate.<br>

### Final Project
The subject we chose for our final project was the effectiveness of a college degree, which we evaluated by comparing data on earned college degrees against data for post-graduation income. We gathered data from the [US Dept. of Education's College Scoreboard](https://collegescorecard.ed.gov/data) site, and from there selected the data from "Most Recent Institution-Level Data" and the "Most Recent Data by Field of Study". We filtered the dataset for datapoints from Bachelor Degrees earned in colleges in and around Seattle, and only datapoints where the degree holder's median income was available. <br>

The slideshow we created to report our findings is available under Final Project.
